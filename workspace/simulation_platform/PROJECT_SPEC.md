# simulation-platform

## Stack

React 18 + Vite + TypeScript, Node.js 20 Express, Socket.IO

## Description

A minimal web‑based simulation platform with real‑time telemetry via WebSocket.

## Setup Commands

- `cd frontend && npm install`
- `cd backend && npm install`

## Run Commands

- `cd backend && npm run dev`
- `cd frontend && npm run dev`

## Test Commands

- `cd backend && npm run build`
- `cd frontend && npm run build`
