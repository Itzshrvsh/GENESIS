# ai-fullstack

## Stack

React (Vite) + TypeScript, Node.js (Express) + TypeScript

## Description

Minimal full‑stack web application with a Vite React frontend and an Express backend. Users can submit a prompt, receive generated output, and view results in memory.

## Setup Commands

- `cd frontend && npm install`
- `cd backend && npm install`

## Run Commands

- `cd frontend && npm run dev`
- `cd backend && npm run dev`

## Test Commands

- `cd frontend && npm run build`
- `cd backend && npm run build`
